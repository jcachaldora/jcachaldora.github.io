# Personal site

Live at https://jcachaldora.github.io

`index.html` is the whole site: one static HTML file with embedded CSS,
no build step, no dependencies, no analytics. Fonts are loaded from
Google Fonts; everything else is inline.

`og.png` is the 1200x630 social preview card, rendered from the site's
own typography. It is referenced by the Open Graph meta tags and is not
used by the page itself.

Served by GitHub Pages from the root of the default branch.
